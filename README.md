# Directorio de Emprendedores by LCO

Plataforma web comunitaria orientada a dar visibilidad a los emprendimientos, negocios y servicios de la comunidad.

## Objetivo

Centralizar la información de los emprendimientos locales en un espacio digital accesible, intuitivo y adaptable a dispositivos móviles.

## Funcionalidades previstas

- Directorio público de emprendimientos.
- Buscador y filtros por categorías.
- Perfiles individuales de negocios.
- Carrusel de puntos referentes.
- Sección de emprendimientos más consultados.
- El Mural: espacio de avisos generales administrado por los administradores.
- Avisos Comunitarios: publicaciones promocionales temporales de los negocios.
- Panel de administración y gestión de contenido.

## Roles del sistema

- **Admin Master:** control general y creación de administradores.
- **Admin:** gestión administrativa según permisos asignados.
- **User / negocio:** gestión de su propio emprendimiento.

## Tecnologías previstas

| Área | Tecnología |
|------|------------|
| Frontend | Vue.js 3 |
| Estilos  | Tailwind CSS |
| Herramientas frontend | Vite |
| Backend | C# / ASP.NET Core Web API |
| Base de datos | PostgreSQL |
| Control de versiones | Git / GitHub |

## Enfoque de diseño

Desarrollo "Responsive First", priorizando la experiencia móvil y adaptando posteriormente la interfaz a pantallas de mayor tamaño.

## Estructura del proyecto

- `frontend/`: aplicación web.
- `backend/`: API y lógica de negocio.
- `docs/`: documentación y decisiones técnicas.
